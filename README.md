# CDC Monitoring API

REST API for monitoring Change Data Capture (CDC) and data replication pipelines.

## Overview

Tracks replication tasks, metrics (lag, throughput), and errors across CDC jobs.
Built as a backend portfolio project.

## Tech Stack

- **Runtime:** .NET 9
- **Framework:** ASP.NET Core Web API
- **Database:** PostgreSQL
- **ORM:** Entity Framework Core
- **Logging:** Serilog
- **Testing:** xUnit
- **Auth:** JWT
